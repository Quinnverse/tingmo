# 听墨 · 把文字读给你听

一个**纯前端**的文字转语音听读小工具。把要背的内容粘贴进来，自动按句切分、用浏览器自带语音朗读，并像小宇宙播客一样**带同步文稿高亮**，可倍速、单句循环、点句跳转，随时反复听。

> 取名「听墨」：墨即书写，听墨＝听文字。内容存在浏览器本地（IndexedDB），不依赖后端、不泄露、免费。

## 功能
- 📝 粘贴文字，或导入 `.txt` / `.md` / `.pdf` / `.docx` / **图片**，自动 OCR 与分句
- 🔊 浏览器 Web Speech API 中英双语 TTS：中文优先大陆普通话，英文自动切换标准英语音色
- 📜 同步文稿：当前句高亮 + 自动滚动，点哪句从哪句读
- ⏯ 播放 / 暂停 / 上一句 / 下一句 / **↺ 重读当前句**
- 🐢 倍速 0.75×–2×，🔁 单句循环
- 🎤 **每句可录音自背**：录下自己背的，回放和原文对照；可标记「会了」
- 📊 **听读记录**：今日 / 本周 / 本月听了多少句、打卡天数、已会句子、最近 7 天走势
- 💾 内容 / 录音 / 记录都存本地（IndexedDB），关掉再打开仍在
- 📱 移动端适配，播放控制栏固定在底部，阅读长文稿无需来回滚动

## 使用
直接用浏览器打开 `index.html` 即可（建议 Chrome / Edge / Safari，中文嗓音最全）。

## 部署到 GitHub Pages（沿用你现有背诵工具的发布方式）
1. 在 GitHub 新建仓库，例如 `tingmo`。
2. 把本目录 `index.html`、`styles.css`、`app.js` 推上去（注意用相对路径 `./styles.css`、`./app.js`，已配好，可放在仓库子路径下）。
3. 仓库 **Settings → Pages**，Source 选 `main` 分支 `/root`，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/tingmo/`。

## 已知边界（v1）
- 语音质量取决于**系统自带嗓音**：Windows 上为系统中文 SAPI 嗓，可用但偏机器感；macOS / iOS 上嗓音更自然。
- 部分浏览器（尤其旧版）不支持 `speechSynthesis`，会提示换浏览器。
- 暂不支持 PDF / Word 直接导入（v1 只吃纯文本 / Markdown）；需要可后续补解析。
- 想换**真人级音质**（如通义 / Edge TTS）时，需要加一个小后端（Cloudflare Worker 转发），到时再扩展。

## 关于「录音自背」与 AI 校验
- 当前每句录音为**自听自检**（纯前端、零成本）：听原句 → 录音背 → 回放对照 → 标记「会了」。主动提取比被动听更记得住。
- 自听的局限：人容易以为自己背对了。要做到「AI 自动判对错」，需要把录音做中文语音识别(ASR)再和目标句比对，须加后端 / API key（如通义听悟、讯飞、Whisper）。可作为后续升级，现有录音数据可直接喂给 ASR。
